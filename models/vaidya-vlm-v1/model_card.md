# Vaidya VLM v1.0.4

**Domain-specialized vision-language model for multimodal health assessment.**

## Overview

Vaidya VLM is a fine-tuned vision-language model specialized for medical image analysis and health Q&A across four clinical domains. Built on the Llama 3.2 90B Vision architecture and further refined via Proximal Policy Optimization (PPO) reinforcement learning with domain-specific reward modeling.

## Training Methodology

### Phase 1 — Supervised Fine-Tuning (SFT)
- Dataset: ~180K curated medical image-text pairs
- Sources: anonymized clinical image datasets, medical literature figures, dermatology atlases, ophthalmology image banks
- Training: 2 epochs, cosine LR schedule, 4 × A100-80GB

### Phase 2 — Reinforcement Learning (PPO-RLHF)
- Teacher model: `meta/llama-3.2-90b-vision-instruct` via NVIDIA NIM API
- Reward signal: combined score of medical accuracy, safety compliance, hallucination rate, and user-preference alignment
- RL steps: 12,400
- KL penalty coefficient: 0.05 (prevents divergence from base model)
- Reward shaping: penalizes ungrounded claims, missing disclaimers, incorrect anatomical references

### Reward Model Architecture
- Separate 7B classifier fine-tuned on preference pairs
- Preference pairs generated by comparing teacher model outputs vs candidate outputs
- Categories scored independently with domain-specific rubrics

## Languages

English, Hindi, Chinese (Simplified), Spanish, French, German, Japanese, Arabic, Italian, Portuguese

## Limitations

- Not a substitute for professional medical diagnosis
- Performance may degrade on rare conditions with limited training data
- Image quality sensitivity: blurry or low-resolution inputs reduce accuracy
- Cultural context variation in mental health assessments

## Inference

```python
from vaidya.model import VaidyaVLM

model = VaidyaVLM.from_pretrained("./models/vaidya-vlm-v1")
response = model.analyze(
    image_path="scan.jpg",
    prompt="Analyze the posture in this image.",
    category="posture",
    language="en"
)
```
